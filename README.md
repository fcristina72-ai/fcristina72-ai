### O que eu entendi dos comandos executados:

Depois de rodar os comandos, entendi que o processo do Git funciona como linhas que servem para salvar meus códigos.

* **git init:** É o ponto inicial. comando que indica que aquela pasta agora é um projeto do Git e que ele precisa começar a rastrear tudo o que acontece ali dentro.

* **git add:** Funciona como se eu estivesse selecionando quais arquivos modificados eu quero colocar dentro de uma caixa para envio. Ele prepara os arquivos (coloca na área de *staging*) antes do salvamento definitivo.

* **git commit:** É o salvamento oficial. Quando eu dou o commit com uma mensagem (tipo `git commit -m "meu primeiro código"`), o Git tira uma foto do estado atual do meu projeto e guarda no histórico local do meu computador.

* **git push:** É o comando que pega tudo o que eu salvei localmente (os commits) e "migra" para a nuvem, atualiza o meu repositório no site do GitHub para que outras pessoas consigam ver.
